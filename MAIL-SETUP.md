# Приём заявок через Web3Forms

## Предыдущий сервис и резервная отправка

Прежняя настройка FormSubmit в HTML направляла обращения на 410012a@gmail.com. Ранее в архиве был FormSubmit с dansal08@mail.ru. Смена получателя сама по себе не устраняет недоступность сервиса.

29 октября 2026 FormSubmit отвечал HTTP 521 на реальные запросы. Сервер сервиса недоступен; отсутствие CORS на ответе приводит к сетевой ошибке в браузере. Письмо не считается отправленным. Автоматических повторов нет.

После ошибки посетитель может открыть письмо/WhatsApp с введённым текстом или скопировать его. Это ручная резервная отправка через приложение посетителя; получение бюро не гарантируется открытием ссылки.

## Текущее подключение Web3Forms

Аккаунт Web3Forms настроен владельцем под vlad.volkov08@bk.ru. Публичный access_key получен из страницы Your Form is Ready и включён в HTML. Это публичный идентификатор формы, а не пароль или секретный API-ключ. Текущий получатель автоматических заявок — 410012a@gmail.com; почта для самостоятельного обращения и резервных ссылок — тот же адрес.

В index.html у contact-form настроены параметры маршрутизации:

- action="https://api.web3forms.com/submit"
- data-endpoint="https://api.web3forms.com/submit"
- data-provider="web3forms"
- data-access-key — публичный ключ из панели владельца

Упоминание сервиса в intake-notice обновлено. Существующие предупреждение, валидация и резервные контакты сохранены. Получатель автоматических заявок задаётся в панели work form → Settings → Email Configuration → Recipient Emails; публичный access_key идентифицирует форму и при смене получателя не меняется.

29 октября 2026 обновлённая локальная форма отправила настоящий тест PB-WEB3-20261029-01 через API Web3Forms на прежний адрес vlad.volkov08@bk.ru. Получен успешный HTTP и success:true; пользователь подтвердил получение письма во входящих на этом адресе. Это исторический тест, не подтверждение доставки на 410012a@gmail.com. Проверка телефона без выдуманного email и Reply-To включена в автоматические тесты. После слияния и публикации нужно один раз повторить сквозную проверку на основном URL сайта.

Документация: https://docs.web3forms.com/getting-started/api-reference и https://docs.web3forms.com/getting-started/installation

После смены получателя выполнен реальный тест PB-WEB3-20261029-02 из локального интерфейса через API Web3Forms. Интерфейс показал «Обращение отправлено: почтовый сервис принял запрос. Спасибо за обращение.»; ошибок и предупреждений в консоли нет. Пользователь подтвердил «Письмо пришло» на вопрос именно об этом маркере и 410012a@gmail.com. Полный цикл локальный интерфейс → настоящий Web3Forms → входящие Gmail подтверждён.

Версия формы пока не опубликована на production, PR №9 открыт. Подтверждённый локальный тест через реальный сервис не является проверкой опубликованного сайта. После слияния и публикации нужно повторить сквозной тест на основном URL.
