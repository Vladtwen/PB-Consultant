# ПБ Консультант — многостраничная версия

Статический сайт без сборки. Главная находится в корневом `index.html`.

- `css/editorial.css` — общий адаптивный дизайн.
- `uslugi/index.html` — каталог из 11 направлений; каждое направление имеет собственную страницу.
- `praktika/tamozhennaya-stoimost.html` — полное описание дела А40-95314/2024, клиент обезличен.
- `js/main.js`, `js/form-service.js` — форма и меню главной; `js/navigation.js` — меню внутренних страниц.
- `js/page-loader.js` — показ главной после готовности первого изображения, с независимым аварийным раскрытием через 8 секунд.
- `images/sunlit-*.webp` — созданные для сайта тёплые архитектурные изображения; происхождение и промпты в `IMAGE-ASSETS.md`.

Страницы открываются обычными ссылками, без предварительной загрузки всего каталога. Нижнее изображение главной загружается по мере приближения к нему. Прежние адреса страниц услуг сохранены. Старые стили и скрипты оставлены в репозитории, но новая главная их не загружает.

Для просмотра запустите любой статический HTTP-сервер из корня репозитория. Публикация на Cloudflare описана в `CLOUDFLARE.md`.

## Правки по визуальному обзору

`css/review-refinements.css` — команда без фото, выравнивание шагов, бургундский третий шаг, контраст формы и адаптивный блок контактов. Снимок узора в деле — `images/architecture-detail.webp`.

`images/customs-chase.svg` хранит исходник иконки грузовика и пакмана. Он встроен в главную, каталог и таможенную страницу; при правке синхронизируйте три вставки. `css/customs-chase.css` и `js/customs-chase.js` воспроизводят сцену один раз при появлении: фура въезжает, виляет и теряет груз, пиксельный пакман догоняет её и съедает коробки, фура уезжает, остаётся пакман. Наведение или фокус повторяют закончившуюся сцену. На сенсорных экранах также работает однократный запуск при появлении; reduced-motion показывает статичного пакмана.

По запросу заказчика поле согласия удалено из формы и проверки. Письмо не содержит утверждения о полученном согласии. Отдельная галочка ознакомления с предупреждением перед отправкой сохранена.


## Компактный первый экран и поле сообщения

`css/compact-hero.css` уменьшает архитектурный блок до 340 px на компьютере, адаптирует изображение и размеры текста на телефоне. Новый декоративный фон в духе Гауди — `images/gaudi-stone-hero.webp` (64 КБ) с JPG-версией; происхождение и промпт в `IMAGE-ASSETS.md`.

`js/textarea-autosize.js` измеряет переносы сообщения. Поле начинается с одной строки, растёт до шести, затем прокручивается внутри; при удалении текста снова сжимается. Учитываются вставка текста, изменение ширины, восстановление страницы и подстановка с событием input. Ручное растягивание отключено; без JavaScript доступна нативная прокрутка однострочного поля.
